# C&C Valeting — website concept

A complete, responsive website proposal for C&C Valeting, a mobile car cleaning business in Carlisle and surrounding areas.

**Live demo:** https://TimOk05.github.io/-c.cvaleting/

## Run locally

Requires Node.js 20 or newer. No package installation is needed.

```sh
npm run dev
npm run check
npm run build
```

Open the local URL printed by the development server. `npm run build` produces the static site in `dist/`. GitHub Actions validates and deploys it to GitHub Pages on pushes to `main`.

## Included

- Responsive mobile and desktop layouts, locally hosted fonts and images.
- Service shortcuts, mobile navigation, interactive detail selector and FAQ accordions.
- Enquiry builder that composes a message locally, with copy-to-clipboard and an Instagram link.
- Accessible labels, keyboard focus, reduced-motion support and privacy information.
- Relative asset paths that work under the GitHub repository subpath.
